# SentinelRAG

Evidence-grounded Android security analysis using static analysis, security RAG, and LLM reasoning.

> 🚧 Prototype under active development

## What is SentinelRAG?

SentinelRAG is a from-scratch Android security analysis platform designed to identify security vulnerabilities in APKs using a hybrid approach:

APK
→ Reverse Engineering
→ Static Detection
→ Evidence Extraction
→ Security RAG
→ LLM Reasoning
→ Evidence Validation
→ Security Report

## Current Prototype

The initial prototype targets:

- SQL Injection
- Hardcoded Secrets
- Insecure WebView
- Exported Components
- Intent Redirection
